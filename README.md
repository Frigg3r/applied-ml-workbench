# Applied ML Workbench

## English

A collection of machine learning implementations, experiments, and applied research using Python and Jupyter notebooks.

The repository focuses on understanding machine learning algorithms, exploring data, evaluating models, and solving practical problems.

## Русский

Коллекция реализаций алгоритмов машинного обучения, экспериментов и прикладных исследований с использованием Python и Jupyter Notebook.

Основное внимание уделяется изучению алгоритмов машинного обучения, анализу данных, оценке качества моделей и решению практических задач.
